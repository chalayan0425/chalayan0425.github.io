# 回光療癒

這是一個可以直接放到 GitHub Pages 的靜態小遊戲。

## 檔案內容

- `index.html`：遊戲主頁
- `1.JPG` 到 `10.JPG`：十張牌圖
- `8.jpg`：第 8 張牌圖
- `.nojekyll`：讓 GitHub Pages 直接照原檔案發布

## 上傳到 GitHub Pages

1. 在 GitHub 建立一個新的 repository。
2. 把這個資料夾裡的所有檔案上傳到 repository 根目錄。
3. 到 repository 的 `Settings`。
4. 左側選 `Pages`。
5. `Build and deployment` 選 `Deploy from a branch`。
6. Branch 選 `main`，資料夾選 `/root`，按 `Save`。
7. 等幾分鐘後，GitHub 會提供一個公開網址。

拿到公開網址後，就可以用那個網址重新產生 QR Code，大家掃描就能玩。
